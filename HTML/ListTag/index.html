List Tags in HTML

In HTML, there are two main types of lists: ordered lists and unordered lists.

Ordered List

  1. First item
  2. Second item
  3. Third item

Unordered List

  • First item

  • Third item

Lists can also be nested, meaning you can have a list within a list. Here's an example:

  • First item
    • Nested item 1
    • Nested item 2
  • Second item
  • Third item

You can also use the type attribute to change the style of the list markers. For example, you can use
type="A" for uppercase letters,
type="a" for lowercase letters,
type="1" for numbers,
type="I" for uppercase Roman numerals, and
type="i" for lowercase Roman numerals.
type=square for square bullets,
type=circle for circle bullets,
and type=disc for disc bullets.
